# AVD Roadmap

## Stage 1 - Foundation

Resource group, VNet/subnet, NSG, Log Analytics, Terraform remote state.

## Stage 2 - Windows

One small Windows VM, PowerShell administration, patching, Azure Monitor Agent.

## Stage 3 - AVD

AVD host pool, workspace, application group, one session host, RBAC, monitoring.

## Stage 4 - Golden image

Windows baseline, application installation, optimization, security configuration, validation, image versioning, Azure Compute Gallery.

## Stage 5 - Automation

Session-host start/stop, drain mode, health checks, remediation, scheduled operations.

## Stage 6 - Interview scenarios

Terraform plan/apply, Git rollback, image version rollback, AVD host troubleshooting, FSLogix troubleshooting, Intune/Entra integration, Azure Monitor/KQL, and PowerShell automation.
